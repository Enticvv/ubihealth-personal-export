# UbiHealth Lab — Personal Health Export

Informational website for the personal Google Health-to-Box export pilot.

The privacy policy and terms are review drafts and are not yet effective. Hosting this draft is not Google verification or approval to enroll participants.

## Hosting

Use GitHub Pages with `main` and the repository root as the publishing source. All navigation and stylesheet paths work under a project URL. No build step is required.

Only the informational HTML, CSS, and this README belong in this repository. Do not add health exports, account tokens, or private project files.
